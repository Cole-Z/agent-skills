# Idea to one-pager

Use when the user has a side project or small-business idea and needs a crisp plan, not a brainstorm dump.

## Goal
Produce a one-page brief they can act on this week.

## Steps
1. Capture the idea in one sentence (restate for confirmation if unclear).
2. Fill these sections briefly (bullets, not essays):
   - **Problem** — who hurts and how
   - **Customer** — specific first buyer or user
   - **Offer** — what you sell or ship
   - **Wedge** — why you, why now (skills, access, timing)
   - **Trust / compliance angle** — only if relevant (privacy, security, regulated domain)
   - **Competition** — 2–3 alternatives and how this differs
   - **Next 3 actions** — concrete, this week, under 2 hours each where possible
3. Flag one decision the user must make (scope, audience, build vs buy, name, etc.).
4. Ask whether to save it as an active project and set a weekly check-in.

## Style
Short, direct, no filler. Prefer decisions over options lists. If the idea is too vague, ask one clarifying question before drafting.
